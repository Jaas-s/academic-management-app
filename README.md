Aplicación móvil multiusuario para la gestión académica desarrollada con React Native y SQLite.

# Academic Management App

Aplicación móvil enfocada en la administración académica con múltiples roles de usuario, permitiendo la gestión y organización de información académica mediante una interfaz intuitiva.

## Tecnologías
- React Native
- Expo
- SQLite
- API


## Funcionalidades
- Gestión de usuarios
- Administración de datos académicos
- Persistencia local con SQLite
- Navegación entre roles
